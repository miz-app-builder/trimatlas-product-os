# Project Structure

## Overview

This document defines the recommended project organization for TrimAtlas Product OS implementation.

## Core Directories

```text
src/
  application/
  domain/
  infrastructure/
  shared/

tests/
  unit/
  integration/
  e2e/

config/
  environments/
  settings/

packages/
  reusable-modules/
```

## Structure Principles

- Keep responsibilities separated
- Maintain clear module boundaries
- Support scalable development
- Encourage reusable components

## Development Guidelines

New features should follow the project structure and align with engineering standards.

## Continuous Improvement

The project structure should evolve as TrimAtlas Product OS architecture grows.
