# TrimAtlas Web

The web app is the Next.js frontend for TrimAtlas Product OS.

## Current Capabilities

- Next.js app-router shell
- TailwindCSS configuration
- shadcn/ui-compatible utility structure
- Initial reusable `Button` component
- Product OS landing dashboard listing planned enterprise modules

## Local Development

```bash
npm install
npm run dev:web
```

The web app listens on port `3000` by default.
